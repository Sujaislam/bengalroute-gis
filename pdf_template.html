1. Executive Summary & Project Objectives

The PathFinder GIS Engine is a full-stack geographic routing application built to compute, visualize, animate, and benchmark four fundamental graph pathfinding algorithms: BFS (Breadth-First Search), DFS (Depth-First Search), Dijkstra’s Algorithm, and A* (A-Star) Search.

The spatial network directly models the sovereign territory of Bangladesh, connecting 32 administrative district headquarters (Jelas) across all 8 divisions (*Dhaka, Chattogram, Sylhet, Rajshahi, Rangpur, Khulna, Barishal, Mymensingh*), with great-circle road distances calculated using the Haversine formula across national highways (N1, N2, N3, N5, N6, N7, N8, and the Padma Bridge corridor).

2. Algorithmic Foundations & Mathematical Analysis

A. Breadth-First Search (BFS)

Concept: An unweighted search algorithm exploring the graph level by level using a FIFO queue. BFS guarantees finding the path with the minimum number of road segments (hops).

Mathematical Properties: Time Complexity: $\mathcal{O}(V + E)$, Space Complexity: $\mathcal{O}(V)$. On weighted road networks, BFS does not evaluate kilometer distances, which can lead to longer total distance paths if long road segments are chosen.

B. Depth-First Search (DFS)

Concept: Explores deeply along each branch using a LIFO stack before backtracking.

Pedagogical Purpose: Demonstrates why DFS is unsuitable for shortest-path routing. Between Dhaka and Chattogram, DFS takes a massive detour through 20 hops and 1,329.6 km (+1,097.4 km excess detour) because it commits to deep paths without evaluating road proximity or goal direction.

C. Dijkstra’s Shortest Path Algorithm

Concept: A uniform-cost search using a min-heap priority queue ordered by cumulative path distance $g(n)$.

Mathematical Guarantee: Guarantees the exact global minimum distance on non-negative weighted graphs. It expands radially in concentric circles outward from the origin, exploring 29 of 32 nodes.

D. A* (A-Star) Search Algorithm & Haversine Heuristic

Concept: An informed search algorithm evaluating nodes by $f(n) = g(n) + h(n)$, where $g(n)$ is actual distance from origin and $h(n)$ is the straight-line Haversine distance to destination.

Admissibility Proof: Because straight-line distance is physically the absolute shortest distance between two geographic coordinates on Earth, $h(n) \le d^*(n)$ always holds true. Thus, A* is guaranteed to find the identical global minimum distance as Dijkstra ($232.2\text{ km}$), while exploring only 7 nodes (a 75.8% search reduction).

5. Setup, Installation & Execution Manual

1. Requirements & Prerequisites

  • Python 3.10 or higher installed.
  • Microsoft Windows, Linux, or macOS.
  • Active internet connection for Google Maps JavaScript tiles.

2. Step-by-Step Installation Commands

# Navigate to project directory
cd C:\Users\suja\map_pathfinder

# Install dependencies
python -m pip install -r requirements.txt

# Apply database migrations
python manage.py makemigrations routing
python manage.py migrate

# Seed Bangladesh Jelas and Dhaka Metro networks
python manage.py seed_graph

# Run automated test suite
python manage.py test routing

# Start development server
python manage.py runserver 127.0.0.1:8000

4. REST API Endpoint Reference

Endpoint Method Parameters Description
`/api/graph/` GET `region` (bangladesh/dhaka) Returns complete graph topology (nodes, coordinates, divisions, and highway edges).
`/api/find-path/` GET / POST `source`, `destination`, `algorithm`, `region` Executes specified algorithm (`bfs`, `dfs`, `dijkstra`, `a_star`) and returns coordinates, distance, and itinerary.
`/api/compare/` GET / POST `source`, `destination`, `region` Executes all 4 algorithms and returns complete comparative benchmark analytics.
